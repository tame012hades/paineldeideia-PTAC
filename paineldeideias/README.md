Painel de Ideias

Um projeto desenvolvido em React para criar, concluir e remover ideias.

Funcionalidades

Adicionar novas ideias
Marcar ideias como concluídas
Remover ideias
Mostrar o total de ideias
Mostrar quantas ideias foram concluídas
Mostrar mensagem de erro quando o campo estiver vazio

Tecnologias

React
Vite
JavaScript
CSS
